# 塔罗系列 · 卡面素材

共 79 张 PNG 卡面，供卡片项目引用。

- 大阿卡纳 23 张
- 宝剑 14 张
- 圣杯 14 张
- 星币 14 张
- 权杖 14 张

## 引用前缀

- CDN（推荐，带 CORS 与缓存）：`https://cdn.jsdelivr.net/gh/guiguhe/tarot-series@main/`
- raw 备用：`https://raw.githubusercontent.com/guiguhe/tarot-series/main/`

## 清单

- `链接清单.md` — 全部卡面，按塔罗顺序
- 小阿卡纳链接清单.md — 小阿卡纳 56 张
- `links.txt` / `小阿卡纳links.txt` — 纯 URL，每行一条

中文文件名已做 URL 编码，可直接粘贴使用（浏览器里写中文原样也能用）。
